# crypto_channels_foreign

Выгрузка **зарубежных крипто-каналов Telegram**, собранная из публичных
страниц TGStat, плюс воспроизводимая механика парсинга.

Репозиторий приватный. Данные — публичная статистика каналов; никакие
закрытые данные, токены или доступы здесь не хранятся.

## Что внутри

```
out/
  crypto_channels_foreign.xlsx      # итоговая таблица, 32 канала
  result_tg_links.txt               # 32 ссылки из итоговой таблицы
  result_tg_links_unverified.txt    # 90 сырых кандидатов до проверки
parsing/
  tgstat_parser.py                  # реконструкция парсера TGStat
  queries.txt                       # примеры поисковых запросов
  requirements.txt
```

### Итоговая таблица

`out/crypto_channels_foreign.xlsx`, лист `crypto_foreign`, 32 строки:

| Колонка | Что значит |
| --- | --- |
| `Ссылка` | ссылка на канал (`t.me`) или карточку TGStat |
| `Название` | название канала |
| `Подписчики` | число подписчиков |
| `ERR%` | вовлечённость постов за всё время |
| `ERR24%` | вовлечённость за последние 24 часа |
| `Язык` | язык аудитории, если TGStat его определил |

Срез по данным:

- подписчики: **152 290 — 1 008 064**;
- `ERR%`: **15.3 — 57.2**, таблица отсортирована по убыванию ERR;
- `ERR24%`: **5.2 — 43.4**;
- язык явно определён у 6 каналов (`en`), у остальных TGStat язык не отдал.

## Механика парсинга

Оригинальные скрипты в папке не сохранились — остались только выгрузки.
`parsing/tgstat_parser.py` восстанавливает пайплайн по структуре таблиц и по
рабочему парсеру `tg_parser_bot`, которым собирались эти же данные.

1. **Поиск.** Открывается `https://tgstat.ru/channels/search`.
2. **Фильтры.** Выставляются:
   - категория `crypto`;
   - язык (для зарубежного среза — английский, код `12`);
   - диапазон подписчиков (для крупных каналов — от 100 000);
   - поисковое слово (`crypto`, `bitcoin`, `ethereum`, `defi`, `solana`,
     `airdrop` и т.п. — см. `parsing/queries.txt`);
   - галочка «искать в описании» (`inAbout`).
3. **Сбор карточек.** Из HTML-выдачи вытаскиваются ссылки вида
   `/channel/@username`, название, тип и текст карточки; из текста сразу
   берётся число подписчиков.
4. **Карточка канала.** Для каждого `@username` открывается
   `https://tgstat.ru/channel/@username` и парсится:
   - название (вторая строка страницы);
   - описание — текст между строкой `@username` и блоком
     «Связанные каналы»;
   - гео и язык — из строки «Гео и язык канала»;
   - контакты — все `@handle` из описания, с пометкой, стоит ли рядом слово
     из админского контекста (`admin`, `поддержка`, `обмен`, `заказать`…).
5. **Статистика.** Открывается `https://tgstat.ru/channel/@username/stat` и
   регулярками вытаскиваются `ERR%`, `ERR24%` и охват одного поста.
6. **Фильтрация и сортировка.** Каналы с высоким ERR и крупной аудиторией
   попадают в итоговый лист, сортировка — по `ERR%` по убыванию.
7. **Экспорт.** `openpyxl` пишет `.xlsx`, параллельно сохраняется `.txt` со
   ссылками. Сырые кандидаты до обогащения — `result_tg_links_unverified.txt`.

Паузы между запросами 45–75 секунд: TGStat показывает капчу при частых
запросах. Парсер работает через уже запущенный Edge по CDP
(`--remote-debugging-port=9222`), авторизация в TGStat — в этом браузере.

## Как воспроизвести

```bash
pip install -r parsing/requirements.txt

# Edge с отладочным портом и вашим профилем TGStat
"C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" \
  --remote-debugging-port=9222 \
  --user-data-dir="C:\Users\Hp\AppData\Local\Temp\opencode\edge_profile"

python parsing/tgstat_parser.py \
  --query crypto --query bitcoin --query ethereum --query defi \
  --category crypto --language 12 \
  --subs-from 100000 --subs-to 2000000 \
  --out out/parsed_foreign.xlsx
```

Без `--query` скрипт не запустится: список запросов передаётся явно или
берётся из `parsing/queries.txt`.

## Ограничения

- TGStat меняет вёрстку и включает антибот — селекторы могут потребовать
  правки; при капче скрипт останавливается с понятной ошибкой.
- Язык/гео TGStat отдаёт не для всех каналов, поэтому часть ячеек пустая.
- Выгрузка — снимок на дату сбора; цифры в TGStat меняются.
